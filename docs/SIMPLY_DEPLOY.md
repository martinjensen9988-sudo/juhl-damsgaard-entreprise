# Deploy to Simply.com

Simply.com webhosting can host this app as a static React/Vite site. It cannot run SSR or Node.js server processes on ordinary webhosting, so the Base44 backend, entities and functions must stay hosted externally unless they are migrated to another backend.

## What Moves To Simply

- The built frontend files from `dist/`
- Static assets generated by Vite
- `.htaccess` for HTTPS, asset caching and React Router deep links

## What Does Not Move Automatically

- `base44/functions/*`
- Base44 entities/database
- Base44 authentication and API runtime

Those pieces still run through Base44 unless you replace them with a separate backend.

## Build

1. Create `.env.production` from `.env.simply.example`.
2. Fill in the Base44 values:

```bash
VITE_BASE44_APP_ID=your_base44_app_id
VITE_BASE44_APP_BASE_URL=https://your-base44-app.example
```

3. Build and verify:

```bash
npm install
npm run build:simply
```

## Upload

Upload the contents of `dist/` to the domain's `public_html` folder at Simply.com.

Important: upload the contents inside `dist/`, not the `dist` folder itself.

The uploaded folder should include:

- `index.html`
- `.htaccess`
- `assets/`

## Test After Upload

Open these URLs on the Simply domain:

- `/`
- `/kontakt`
- `/login`
- `/dashboard`
- `/sikkerhed-apv`

Refresh each page directly in the browser. If refresh works, the `.htaccess` router fallback is working.

## Known Limitations

- If the app needs Base44 functions, the Simply-hosted frontend must still call the hosted Base44 backend.
- If the whole system must be independent from Base44, the next project phase is backend migration: database schema, auth, file storage and every `base44/functions/*` endpoint.
